# 云函数接口文档（uniCloud 版）

## 1. 文档说明
本项目后端基于 uniCloud 云函数，每个云函数等价一个接口端点。
前端统一通过 `callCloud(functionName, payload)` 调用。

- 调用入口：`/Users/zengzeng/Desktop/HBuilderProjects/salon-booking-app/api/client.js`
- 统一响应封装：`/Users/zengzeng/Desktop/HBuilderProjects/salon-booking-app/uniCloud-aliyun/cloudfunctions/common/sb-common/withResponse.js`

统一返回结构：
```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "requestId": ""
}
```
- `code = 0` 表示成功
- 业务失败常见错误码：`401/403/409/422`

## 2. 认证与用户

### 2.1 `auth-register`
- 说明：用户注册
- 主要入参：`username, password, role, displayName?`
- 返回：用户基础信息与登录态

### 2.2 `auth-login`
- 说明：账号登录
- 主要入参：`username, password`
- 返回：`token` 与用户信息（含 `serviceIds[]`）

### 2.3 `auth-me`
- 说明：获取当前登录用户
- 主要入参：无
- 返回：当前用户信息（含 `serviceIds[]`, `intro`）

### 2.4 `user-bind-phone`
- 说明：绑定手机号
- 主要入参：`phone, code`
- 返回：绑定结果

### 2.5 `user-profile-update`
- 说明：更新个人资料
- 主要入参：`username?/name?, avatar?, intro?`
- 补充：
  - `username` 与 `name` 二选一，后端统一按账号名处理
  - `intro` 为理发师擅长介绍，支持传空字符串清空
- 返回：更新后的用户信息

### 2.6 `sms-send-code`
- 说明：发送短信验证码
- 主要入参：`phone, purpose?`
- 返回：发送结果（包含倒计时等辅助字段）

### 2.7 `sms-verify-code`
- 说明：校验短信验证码
- 主要入参：`phone, code, purpose?`
- 返回：验证码是否有效

### 2.8 `password-reset`
- 说明：重置密码
- 主要入参：`phone, code, password`
- 返回：重置结果

## 3. 门店与服务

### 3.1 `stores-list`
- 说明：门店列表（支持搜索/筛选/排序：默认/评分/价格）
- 主要入参：`keyword?, sortBy?, minRating?, maxPrice?, tags?, userLat?, userLng?, maxDistance?, page?, pageSize?`
- 补充：
  - `sortBy`：`default/rating/price/distance`
  - 当 `sortBy=price` 或传入 `maxPrice` 时，价格按“门店 `minPrice` 与服务最低价的较小值”计算
- 返回：门店列表

### 3.2 `stores-detail`
- 说明：门店详情
- 主要入参：`id`
- 返回：门店详情对象

### 3.3 `stores-services`
- 说明：门店服务列表
- 主要入参：`id`（storeId）
- 返回：服务列表

### 3.4 `stores-barbers`
- 说明：门店理发师列表
- 主要入参：`id`（storeId）
- 返回：理发师列表（含 `intro`, `serviceIds[]`）

### 3.5 `store-update-profile`
- 说明：管理员更新门店资料
- 主要入参：`storeId, patch`
- 约束：
  - `patch.services` 提交时不能为空
  - 服务价格必须 `> 0`
  - 提交服务后会自动同步门店 `minPrice`（取服务最低价）
- 返回：更新结果

### 3.6 `barber-services-set`
- 说明：设置理发师可服务项目
- 主要入参：`storeId, assignments[]`
- 返回：保存结果

## 4. 订单核心

### 4.1 `orders-create`
- 说明：创建预约
- 主要入参：`storeId, serviceId, barberId, date, startTime, remark?`
- 返回：新订单信息（含核验码）

### 4.2 `orders-mine`
- 说明：我的订单列表
- 主要入参：`status?, page?, pageSize?, lastSyncAt?`
- 返回：`{ list, lastSyncAt }`

### 4.3 `orders-detail`
- 说明：订单详情
- 主要入参：`id`
- 返回：订单详情（含 `queueAheadCount/queueWaitMin`）

### 4.4 `orders-cancel`
- 说明：取消订单
- 主要入参：`orderId, reason?`
- 状态约束：通常仅 `BOOKED` 可取消

### 4.5 `orders-reschedule`
- 说明：改期订单
- 主要入参：`orderId, newDate, newStartTime`
- 状态约束：通常仅 `BOOKED` 可改期

### 4.6 `orders-verify`
- 说明：核验到店（`BOOKED -> ARRIVED`）
- 主要入参：`verifyCode`
- 角色：管理员

### 4.7 `orders-start-service`
- 说明：开始服务（`ARRIVED -> IN_SERVICE`）
- 主要入参：`orderId`
- 角色：管理员/理发师
- 当前约束：`BOOKED` 不允许直接开始

### 4.8 `orders-finish-service`
- 说明：完成服务（`IN_SERVICE -> FINISHED`）
- 主要入参：`orderId`
- 角色：管理员/理发师

### 4.9 `orders-no-show`
- 说明：标记爽约（`BOOKED -> NO_SHOW`）
- 主要入参：`orderId, reason?`

### 4.10 `orders-delete`
- 说明：删除订单（软性业务删除）
- 主要入参：`orderId`
- 说明：通常仅已取消/已完成订单可删除

### 4.11 `orders-store-list`
- 说明：门店订单列表
- 主要入参：`date, lastSyncAt?, limit?`
- 返回：`{ list, lastSyncAt }`
- 补充：返回等位信息 `queueAheadCount/queueWaitMin`

### 4.12 `orders-barber-list`
- 说明：理发师订单列表
- 主要入参：`date, lastSyncAt?, limit?`

### 4.13 `orders-items-list`
- 说明：订单明细项
- 主要入参：`orderId`

### 4.14 `orders-events-list`
- 说明：订单状态变更日志
- 主要入参：`orderId`

## 5. 评价与售后

### 5.1 `reviews-create`
- 说明：创建评价
- 主要入参：`orderId, rating, content?, images?`

### 5.2 `reviews-list`
- 说明：门店评价列表
- 主要入参：`storeId, filter?, page?, pageSize?`
- 返回补充：每条评价会尽量补齐 `serviceId`, `serviceName`（从关联订单回填）

### 5.3 `reviews-by-order`
- 说明：按订单查询评价
- 主要入参：`orderId`

### 5.4 `reviews-mine`
- 说明：我的评价列表
- 主要入参：`page?, pageSize?`

### 5.5 `reviews-delete`
- 说明：删除评价
- 主要入参：`reviewId`

### 5.6 `aftersales-create`
- 说明：提交售后
- 主要入参：`orderId, type, content`

### 5.7 `aftersales-store-list`
- 说明：门店侧售后列表
- 主要入参：`status?`
- 状态说明：
  - 支持 `OPEN/PROCESSING/RESOLVED/REJECTED`
  - 兼容大小写与中文别名（如“待处理/处理中/已解决/未通过/全部”）
  - 返回会统一为大写状态，并包含 `createdAt/updatedAt`

### 5.8 `aftersales-reply`
- 说明：门店回复售后
- 主要入参：`aftersaleId, reply`

### 6.1 `notifications-list`
- 说明：通知列表

### 6.2 `notifications-mark-read`
- 说明：标记已读（单条/全部）

### 6.3 `notifications-delete`
- 说明：删除通知

### 6.4 `notifications-create`
- 说明：创建通知（内部函数，通常由其他业务云函数调用）

### 6.5 `barber-schedule-set`
- 说明：设置理发师排班

### 6.6 `barber-slots-get`

### 6.9 `barbers-manage`
- 说明：理发师管理（列表/重命名/移除）
- 主要入参：`action`（`list`/`rename`/`remove`）及对应参数

- 说明：AI 服务顾问，基于文本/图片给出服务建议

- 返回补充：
  - `recommendations` 会按用户意图（剪/烫/染/护理/头皮）做一致性过滤与补齐
  - 推荐结果按价格升序（同价按时长升序）输出

### 6.11 `seed-data`
- 说明：测试数据初始化

## 7. 接口文档维护规范
1. 新增云函数时，同步在本文件追加“函数名、入参、状态约束、角色限制”。
2. 变更状态机时，必须同时更新：
   - 云函数代码注释
   - 本文档状态约束
   - `docs/测试结论.md` 回归结论
3. 若评审要求“REST 风格文档”，可增加一层映射：
   - `POST /cloud/{functionName}` -> `callCloud(functionName, payload)`
