# 云函数接口文档（uniCloud 版）

## 1. 文档说明
本项目后端基于 uniCloud 云函数，每个云函数等价一个接口端点。
前端统一通过 `callCloud(functionName, payload)` 调用。

- 调用入口：`/Users/zengzeng/Desktop/HBuilderProjects/salon-booking-app/api/client.js`
- 统一响应封装：`/Users/zengzeng/Desktop/HBuilderProjects/salon-booking-app/uniCloud-aliyun/cloudfunctions/common/sb-common/withResponse.js`

统一返回结构：
```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "requestId": ""
}
```
- `code = 0` 表示成功
- 业务失败常见错误码：`401/403/409/422`

## 2. 认证与用户

### 2.1 `auth-register`
- 说明：用户注册
- 主要入参：`username, password, role, displayName?`
- 返回：用户基础信息与登录态

### 2.2 `auth-login`
- 说明：账号登录
- 主要入参：`username, password`
- 返回：token 与用户信息

### 2.3 `auth-me`
- 说明：获取当前登录用户
- 主要入参：无
- 返回：当前用户信息

### 2.4 `user-bind-phone`
- 说明：绑定手机号
- 主要入参：`phone, code`
- 返回：绑定结果

### 2.5 `user-profile-update`
- 说明：更新个人资料
- 主要入参：`displayName?, avatar?`
- 返回：更新后的用户信息

## 3. 门店与服务

### 3.1 `stores-list`
- 说明：门店列表（支持搜索/筛选/排序）
- 主要入参：`keyword?, sort?, page?, pageSize?`
- 返回：门店列表

### 3.2 `stores-detail`
- 说明：门店详情
- 主要入参：`id`
- 返回：门店详情对象

### 3.3 `stores-services`
- 说明：门店服务列表
- 主要入参：`id`（storeId）
- 返回：服务列表

### 3.4 `stores-barbers`
- 说明：门店理发师列表
- 主要入参：`id`（storeId）
- 返回：理发师列表

### 3.5 `store-update-profile`
- 说明：管理员更新门店资料
- 主要入参：`storeId, patch`
- 返回：更新结果

### 3.6 `barber-services-set`
- 说明：设置理发师可服务项目
- 主要入参：`storeId, assignments[]`
- 返回：保存结果

## 4. 订单核心

### 4.1 `orders-create`
- 说明：创建预约
- 主要入参：`storeId, serviceId, barberId, date, startTime, remark?`
- 返回：新订单信息（含核验码）

### 4.2 `orders-mine`
- 说明：我的订单列表
- 主要入参：`status?, page?, pageSize?, lastSyncAt?`
- 返回：`{ list, lastSyncAt }`

### 4.3 `orders-detail`
- 说明：订单详情
- 主要入参：`id`
- 返回：订单详情（含 `queueAheadCount/queueWaitMin`）

### 4.4 `orders-cancel`
- 说明：取消订单
- 主要入参：`orderId, reason?`
- 状态约束：通常仅 `BOOKED` 可取消

### 4.5 `orders-reschedule`
- 说明：改期订单
- 主要入参：`orderId, newDate, newStartTime`
- 状态约束：通常仅 `BOOKED` 可改期

### 4.6 `orders-verify`
- 说明：核验到店（`BOOKED -> ARRIVED`）
- 主要入参：`verifyCode`
- 角色：管理员

### 4.7 `orders-start-service`
- 说明：开始服务（`ARRIVED -> IN_SERVICE`）
- 主要入参：`orderId`
- 角色：管理员/理发师
- 当前约束：`BOOKED` 不允许直接开始

### 4.8 `orders-finish-service`
- 说明：完成服务（`IN_SERVICE -> FINISHED`）
- 主要入参：`orderId`
- 角色：管理员/理发师

### 4.9 `orders-no-show`
- 说明：标记爽约（`BOOKED -> NO_SHOW`）
- 主要入参：`orderId, reason?`

### 4.10 `orders-delete`
- 说明：删除订单（软性业务删除）
- 主要入参：`orderId`
- 说明：通常仅已取消/已完成订单可删除

### 4.11 `orders-store-list`
- 说明：门店订单列表
- 主要入参：`date, lastSyncAt?, limit?`
- 返回：`{ list, lastSyncAt }`
- 补充：返回等位信息 `queueAheadCount/queueWaitMin`

### 4.12 `orders-barber-list`
- 说明：理发师订单列表
- 主要入参：`date, lastSyncAt?, limit?`

### 4.13 `orders-items-list`
- 说明：订单明细项
- 主要入参：`orderId`

### 4.14 `orders-events-list`
- 说明：订单状态变更日志
- 主要入参：`orderId`

## 7. 接口文档维护规范（建议）
1. 新增云函数时，同步在本文件追加“函数名、入参、状态约束、角色限制”。
2. 变更状态机时，必须同时更新：
   - 云函数代码注释
   - 本文档状态约束
   - `docs/测试结论.md` 回归结论
3. 若评审要求“REST 风格文档”，可增加一层映射：
   - `POST /cloud/{functionName}` -> `callCloud(functionName, payload)`
